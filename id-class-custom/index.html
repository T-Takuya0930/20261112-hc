HOME ANIMALS VISIT

森の中で、いきものと出会う。

里山の自然をそのまま活かした、小さな動物園です。

WELCOME

森の動物園は、都市のすぐそばに残る雑木林の中にあります。 柵の向こう側ではなく、同じ森に暮らす隣人として、動物たちの姿を眺めてください。

01. 歩いて、見つける

園内に決まった順路はありません。木漏れ日の小道を歩きながら、 思い思いの場所で動物たちと出会う。そんな時間を大切にしています。

02. 暮らしを、のぞく

食事の時間、昼寝の時間、遊ぶ時間。動物たちの一日をそのまま見られるよう、 展示よりも「暮らし」を優先した環境づくりをしています。
