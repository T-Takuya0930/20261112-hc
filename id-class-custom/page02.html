VISIT

開園時間・アクセス・園内のきまりをご案内します。

INFORMATION

予約は不要です。入口でチケットをお求めください。 混雑しやすいのは、春の連休と紅葉の季節です。

開園時間

9:30 - 16:30（入園は16:00まで）
毎週水曜日と年末年始は休園です。

入園料

大人 500円／こども（4歳〜中学生）200円
3歳以下は無料です。

ACCESS

最寄り駅から徒歩15分。森の中の道を抜けると、入口が見えてきます。 駐車場は20台分あります。

電車でお越しの方

「森山駅」北口から遊歩道をまっすぐ。途中に看板があります。

お車でお越しの方

国道沿いの「森の入口」交差点を曲がり、300m先の駐車場をご利用ください。

RULES

動物たちが安心して暮らせるよう、以下のことにご協力ください。

餌を与えないでください

動物たちの健康のために、園が用意した餌以外は与えないでください。

静かに見守ってください

大きな声や、突然の動きは動物を驚かせてしまいます。 写真を撮るときはフラッシュをオフにしてください。
